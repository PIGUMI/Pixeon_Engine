================================================================================
1. エンジン全体のアーキテクチャ概要
================================================================================

Pixeon Engineは、DirectX11ベースの3Dゲームエンジンで、以下の主要なサブシステムで
構成されています：

主要コンポーネント:
- EngineManager: エンジン全体の管理とライフサイクル制御
- DirectX11 (System.cpp/h): グラフィックスAPI管理
- SceneManager: シーン管理とオブジェクトのライフサイクル
- ComponentManager: コンポーネントシステムの管理
- AssetManager: アセットの読み込みとキャッシング
- ModelManager: 3Dモデル（Assimp経由）の管理
- TextureManager: テクスチャリソースの管理
- ShaderManager: シェーダーのコンパイルと管理
- EditrGUI: エディターUIシステム（ImGui使用）

設計パターン:
- シングルトンパターンを多用（すべてのマネージャークラス）
- コンポーネントベースのオブジェクトシステム
- エンティティ-コンポーネントシステム（ECS）の簡易実装

================================================================================
2. エンジン起動フロー
================================================================================

2.1 初期化シーケンス (EngineManager::Init)
-------------------------------------------
1. COM初期化 (CoInitializeEx)
   - マルチスレッドモードで初期化

2. DirectX11の初期化 (DirectX11::Init)
   - スワップチェーンの作成
   - デバイスとコンテキストの作成
   - レンダーターゲットビューの作成
   - デプスステンシルビューの作成
   - ラスタライザーステートの設定（カリングモード）
   - ブレンドステートの設定（アルファブレンディング等）
   - サンプラーステートの設定

3. 設定の読み込み (SettingManager::LoadConfig)
   - コンフィグファイルからエンジン設定を読み込み

4. AssetManager初期化
   - ルートディレクトリの設定
   - ロードモードの設定
   - 自動同期機能の開始（1秒間隔）

5. ゲーム用レンダーターゲットの作成 (GameRenderTarget)
   - エディターモード用の専用レンダーターゲット

6. GUI初期化 (EditrGUI::Init)
   - ImGuiの初期化
   - フォントロード（日本語対応）
   - エディターアイコンのロード

7. シーンマネージャー初期化 (SceneManger::Init)
   - シーンファイルのスキャン
   - シーンの登録
   - 初期シーンのロード

8. ShaderManager初期化
   - HLSLシェーダーのコンパイル

9. ComponentManager初期化
   - コンポーネント名の登録

================================================================================
3. メインループフロー
================================================================================

3.1 更新フロー (EngineManager::Update)
--------------------------------------
エディットモード時:
  1. ShaderManager::UpdateAndCompileShaders()
     - シェーダーファイルの変更検知と再コンパイル
  
  2. EditrGUI::Update()
     - ImGuiフレームの開始
     - エディターUIの更新
     - ユーザー入力処理
  
  3. SceneManger::EditUpdate()
     - 次シーンへの切り替え処理
     - スレッドセーフな追加処理
     - カメラコンポーネントの更新
     - オブジェクトの編集更新
     - オブジェクトの削除処理
     - オートセーブ機能（設定された間隔で）

ゲームモード時:
  1. SceneManger::PlayUpdate()
     - シーン切り替え
     - シーンの初期化とロード
     - BeginPlayの呼び出し
     - オブジェクトのゲーム更新

3.2 描画フロー (EngineManager::Draw)
------------------------------------
エディットモード時:
  1. GameRenderTarget::Begin()
     - ゲームビュー用のレンダーターゲットをセット
  
  2. SceneManger::Draw()
     - シーン内全オブジェクトの描画
     - コンポーネント単位での描画処理
  
  3. GameRenderTarget::End()
     - レンダーターゲットの終了
  
  4. DirectX11::BeginDraw()
     - デフォルトバックバッファーのクリア
  
  5. EditrGUI::Draw()
     - ImGuiの描画
     - エディターウィンドウ群の描画
  
  6. DirectX11::EndDraw()
     - スワップチェーンのPresent

ゲームモード時:
  1. DirectX11::BeginDraw()
  2. SceneManger::Draw()
  3. DirectX11::EndDraw()

================================================================================
4. シーンとオブジェクトのライフサイクル
================================================================================

4.1 Scene のライフサイクル
--------------------------
1. 生成 (new Scene)
2. Init() - 内部状態の初期化
3. LoadToFile() - ファイルからシーンデータのロード
4. EditUpdate() または PlayUpdate() - 継続的な更新
5. SaveToFile() - ファイルへのセーブ
6. デストラクタ - クリーンアップ

4.2 Object のライフサイクル
---------------------------
1. 生成とシーンへの追加
2. Init() - オブジェクトの初期化
3. BeginPlay() - ゲーム開始時（ゲームモードのみ）
4. EditUpdate() / InGameUpdate() - 継続的な更新
5. Draw() - 描画
6. UInit() - 終了処理
7. delete - メモリ解放

4.3 Component のライフサイクル
------------------------------
1. Object::AddComponent<T>() - コンポーネントの追加
2. Component::Init(Object*) - オーナーの設定と初期化
3. BeginPlay() - ゲーム開始時
4. EditUpdate() / InGameUpdate() - 更新処理
5. Draw() - 描画
6. UInit() - 終了処理
7. delete - メモリ解放

================================================================================
5. リソース管理システム
================================================================================

5.1 AssetManager
----------------
- 役割: 低レベルファイルI/O、キャッシング
- ロードモード: FromSource（ソースファイルから直接）
- 自動同期: ファイルシステム変更の検知（1秒間隔）
- キャッシュ: std::map<std::string, std::vector<uint8_t>>
- スレッドセーフ: std::mutex使用

5.2 ModelManager
----------------
- 役割: 3Dモデルの読み込みと管理（Assimp使用）
- キャッシュ: weak_ptrベースの参照カウント
- サブメッシュ、マテリアル、ボーン、アニメーションの処理
- GPUバッファの作成とメモリ追跡

5.3 TextureManager
------------------
- 役割: テクスチャの読み込みと管理（DirectXTex使用）
- キャッシュ: weak_ptrベースの参照カウント
- Pin/Unpin機能で明示的なキャッシュ制御
- フォーマット: WIC対応形式、TGA

5.4 ShaderManager
-----------------
- 役割: HLSLシェーダーのコンパイルと管理
- 動的リロード: ファイル変更時の自動再コンパイル
- バイトコードキャッシュ
- 定数バッファの自動生成と管理
- リフレクション機能でシェーダーメタデータ取得

================================================================================
6. コンポーネントシステム
================================================================================

6.1 利用可能なコンポーネントタイプ
----------------------------------
- CAMERA: カメラコンポーネント（ビュー・プロジェクション行列）
- GEOMETRY: ジオメトリレンダリング（プリミティブ形状）
- MODEL: 3Dモデルレンダリング（Assimpモデル）
- LIGHT: ライト（Directional, Point, Spot）
- IMAGE: 2D画像レンダリング

6.2 コンポーネント追加フロー
-----------------------------
1. ComponentManager::AddComponent(owner, type)
2. 適切な派生クラスのインスタンス生成
3. Component::Init(owner) - オーナーの設定
4. Objectのコンポーネントリストに追加

6.3 コンポーネント取得
----------------------
- GetComponent<T>(): 型による検索（dynamic_cast使用）
- GetComponent(name): 名前による検索

7. エディターGUIシステム
================================================================================

7.1 主要なエディターパネル
--------------------------
- Hierarchy: シーン内オブジェクトのツリービュー

7.2 GUIとゲームロジックの連携
-----------------------------
- エディターモードとゲームモードの切り替え
- オブジェクトの選択・編集
- コンポーネントの追加・削除
- プロパティのリアルタイム編集

================================================================================
8. スレッドセーフティとマルチスレッド
================================================================================

8.1 マルチスレッド対応箇所
--------------------------
- AssetManager: std::mutex でロード処理を保護
- ModelManager: std::mutex でキャッシュアクセスを保護
- TextureManager: std::mutex でキャッシュアクセスを保護
- Scene: std::mutex でオブジェクト追加処理を保護

8.2 オブジェクト追加のスレッドセーフ処理
----------------------------------------
Scene::AddObject() はスレッドセーフ:
  1. _ToBeAddedBuffer にバッファリング（mutexで保護）
  2. ProcessThreadSafeAdditions() でメインスレッドに転送
  3. EditUpdate() で実際の追加処理

================================================================================
9. セーブ/ロードシステム
================================================================================

9.1 シーンのセーブ (Scene::SaveToFile)
---------------------------------------
- JSON形式でシリアライゼーション（nlohmann/json使用）
- オブジェクト単位で保存
- Transform、コンポーネントデータを含む
- 拡張子: .scene

9.2 シーンのロード (Scene::LoadFromFile)
-----------------------------------------
- JSONファイルの解析
- オブジェクトの再構築
- コンポーネントのロード
- Transform、プロパティの復元

9.3 オートセーブ機能
--------------------
- 設定可能な時間間隔（デフォルト）
- エディットモード中のみ動作
- GetTickCount64()で時間測定

================================================================================
10. 終了処理フロー (EngineManager::UnInit)
================================================================================

1. AssetManager::StopAutoSync() - 自動同期の停止
2. SceneManger::Save() - 現在のシーンを保存
3. SettingManager::SaveConfig() - 設定を保存
4. 各マネージャーの破棄（逆順）:
   - AssetManager
   - ComponentManager
   - SceneManger
   - SettingManager
   - ShaderManager
   - TextureManager
   - ModelManager
   - ResourceService
   - DirectX11
5. CoUninitialize() - COMの終了処理
