透過画像がGameRenderTargetを経由すると透過されない問題の原因
================================================================

問題の概要:
----------
ImagerRenderを使用して描画した透過画像がGameRenderTargetを経由して描画すると、
透過部分が黒く表示されます。しかし、DirectX11に直接書き込むInGameDraw()では
正常に透過されます。

原因分析:
----------

1. InGameDraw()の動作 (EngineManager.cpp 247-251行目):
   - DirectX11のデフォルトレンダーターゲットに直接描画
   - BeginDraw()で背景色でクリア (System.cpp 180-193行目)
   - SceneManger::Draw()で全てのオブジェクトを描画
   - 透過は正常に機能する

2. EditorDraw()の動作 (EngineManager.cpp 226-245行目):
   - GameRenderTarget::Begin()でカスタムレンダーターゲットにレンダリング開始
   - SceneManger::Draw()で全てのオブジェクトを描画
   - GameRenderTarget::End()でデフォルトレンダーターゲットに戻る
   - レンダーターゲットのテクスチャをエディターGUIに表示
   - この過程で透過部分が黒く表示される

根本原因:
----------

ImageRender::EnsureBlendState()メソッド (ImageRender.cpp 105-119行目)で
アルファチャンネルのブレンド設定が正しくありませんでした。

問題のコード:
```cpp
desc.RenderTarget[0].SrcBlendAlpha = D3D11_BLEND_ONE;
desc.RenderTarget[0].DestBlendAlpha = D3D11_BLEND_ZERO;
desc.RenderTarget[0].BlendOpAlpha = D3D11_BLEND_OP_ADD;
```

この設定では:
```
FinalAlpha = SrcAlpha * 1 + DestAlpha * 0 = SrcAlpha
```

つまり、デスティネーションのアルファ値を完全に無視し、ソースのアルファ値で
上書きしてしまいます。

透過画像を描画する際の問題:

1. GameRenderTargetは背景色でクリアされる（alpha=1.0、不透明）

2. 透過画像の透明部分（alpha=0）を描画すると:
   - カラーチャンネル: 
     FinalColor = SrcColor * 0 + DestColor * 1 = 背景色
   - アルファチャンネル:
     FinalAlpha = 0 * 1 + 1 * 0 = 0（完全に透明になってしまう）

3. レンダーターゲット全体のアルファが0になり、ImGuiで表示する際に
   透明として扱われ、背景が透けて黒く見える

解決方法:
----------

アルファチャンネルのブレンド設定を正しく修正します:

```cpp
desc.RenderTarget[0].SrcBlendAlpha = D3D11_BLEND_ONE;
desc.RenderTarget[0].DestBlendAlpha = D3D11_BLEND_INV_SRC_ALPHA;
desc.RenderTarget[0].BlendOpAlpha = D3D11_BLEND_OP_ADD;
```

この設定により:
```
FinalAlpha = SrcAlpha * 1 + DestAlpha * (1 - SrcAlpha)
```

これは標準的な"over"合成演算です。

透過画像を描画する際:
1. レンダーターゲットは背景色でクリアされる（alpha=1.0）
2. 透過画像の透明部分（alpha=0）を描画すると:
   - カラーチャンネル: 
     FinalColor = SrcColor * 0 + DestColor * 1 = 背景色（正しい）
   - アルファチャンネル:
     FinalAlpha = 0 * 1 + 1 * (1 - 0) = 1（不透明を維持）
3. 透過画像の不透明部分（alpha=1）を描画すると:
   - カラーチャンネル: 
     FinalColor = SrcColor * 1 + DestColor * 0 = SrcColor（正しい）
   - アルファチャンネル:
     FinalAlpha = 1 * 1 + 1 * (1 - 1) = 1（不透明を維持）
4. レンダーターゲット全体が適切なアルファ値を持ち、ImGuiで正しく表示される

技術的詳細:
----------

- レンダーターゲットのフォーマット: DXGI_FORMAT_R8G8B8A8_UNORM
  (GameRenderTarget.cpp 18行目)
- 修正前のアルファブレンディング設定:
  - BlendEnable = TRUE
  - SrcBlend = D3D11_BLEND_SRC_ALPHA
  - DestBlend = D3D11_BLEND_INV_SRC_ALPHA
  - BlendOp = D3D11_BLEND_OP_ADD
  - SrcBlendAlpha = D3D11_BLEND_ONE
  - DestBlendAlpha = D3D11_BLEND_ZERO（←問題）
  - BlendOpAlpha = D3D11_BLEND_OP_ADD
- 修正後のアルファブレンディング設定:
  - DestBlendAlpha = D3D11_BLEND_INV_SRC_ALPHA（←修正）
- ピクセルシェーダー: PS_ImgQuad.hlsl
  - テクスチャのアルファ値を保持
  - 頂点カラーとテクスチャカラーを乗算

まとめ:
------

透過画像の描画時に、アルファチャンネルのブレンド設定が不適切だったため、
レンダーターゲットのアルファ値が破壊されていました。DestBlendAlphaを
D3D11_BLEND_INV_SRC_ALPHAに変更することで、標準的なアルファ合成が
実現され、問題が解決されます。
